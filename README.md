# multiplayer-tic-tac-toe
NEONGRID is a real-time 1v1 multiplayer Tic-Tac-Toe arena built with Node.js, Express, and Socket.IO. It features server-authoritative gameplay, Best-of-3/5 matches, turn timers with auto-moves, disconnect forfeits, rematches, procedural Web Audio, and a mobile-optimized neon glassmorphism UI.
